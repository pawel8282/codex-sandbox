# codex-sandbox
Private,
Najpierw wykonaj audyt repozytorium i jego historii bez ujawniania żadnych sekretów. Sprawdź, czy występują klucze prywatne, seed phrases, pliki portfeli, hasła, tokeny API, dane kont albo publiczne adresy kryptowalutowe. Nie pokazuj pełnej treści żadnego sekretu — podaj tylko rodzaj zagrożenia, nazwę pliku i zalecenie.

Następnie na osobnej gałęzi przygotuj bezpieczną konfigurację repozytorium: AGENTS.md, odpowiedni .gitignore, SECURITY.md oraz .env.example bez prawdziwych danych. Nie podłączaj portfeli, nie podpisuj transakcji i niczego nie wysyłaj. Najpierw pokaż plan, potem wykonaj zmiany i przedstaw diff. Nie merguj zmian do main.
